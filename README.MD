# 🚀 Atividade Prática: Contribuição Colaborativa em HTML e CSS

Bem-vindo(a) ao projeto prático da nossa disciplina! O objetivo desta atividade é exercitar a criação de estrutura de páginas com **HTML5**, estilização com **CSS3** e a prática de versionamento colaborativo utilizando **Git** e **GitHub** através de *Pull Requests* (PRs).

---

## 📌 Objetivos da Atividade

1. Praticar a escrita limpa e semântica de HTML5.
2. Aplicar regras de estilização CSS organizadas.
3. Compreender na prática o fluxo de trabalho colaborativo no GitHub (*Fork*, *Branch*, *Commit* e *Pull Request*).

---

## 🛠️ Como Participar (Passo a Passo)

Para enviar suas sugestões de código para os arquivos `index.html` e `estilo.css`, siga as etapas:

1. **Faça um Fork** deste repositório para a sua conta do GitHub.
2. **Crie uma nova Branch** no seu repositório com o seguinte padrão de nome:
   `sugestao-[seu-nome]` (Exemplo: `sugestao-joao-silva`).
3. **Edite os arquivos:**
   - Adicione elementos estruturais no `index.html`.
   - Adicione seletores e regras de estilo no `estilo.css`.
4. **Faça o Commit** das suas alterações com uma mensagem clara e descritiva (Exemplo: `feat: adiciona cabecalho e estilo de botoes`).
5. **Abra um Pull Request (PR)** apontando da sua branch para a branch `main` do repositório original.

---

## 📜 Regras de Contribuição

Para que o seu *Pull Request* seja aprovado e integrado ao projeto, você deve seguir as seguintes diretrizes:

### 1. Organização do Código
- **HTML:** Utilize tags semânticas (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`, etc.).
- **CSS:** Evite estilos em linha (`style="..."`). Todas as regras visuais devem ficar no arquivo `estilo.css`.
- **Indentação:** Mantenha a indentação correta do código (recomenda-se 2 ou 4 espaços).

### 2. Boas Práticas e Respeito
- **Não apague a contribuição de colegas:** Adicione novos elementos ou melhore os existentes sem remover o trabalho já validado sem justificativa.
- **Nomenclatura:** Utilize nomes de classes e IDs em letras minúsculas e separados por hífen (Exemplo: `.menu-principal`, `#btn-enviar`).

### 3. Formatação do Pull Request
Ao abrir o PR, preencha o título e a descrição seguindo o modelo:
- **Título do PR:** `Contribuição: [Seu Nome Completo] - [Breve resumo]`  
  *(Exemplo: Contribuição: Maria Souza - Adiciona formulário de contato)*
- **Descrição:** Explique sucintamente o que você adicionou ou alterou no projeto.

---

## 📋 Checklist de Validação

Antes de clicar em **Create pull request**, verifique:

- [ ] Criei uma branch específica para a minha contribuição?
- [ ] O código HTML está semântico e bem formatado?
- [ ] Os estilos CSS foram colocados exclusivamente no arquivo `estilo.css`?
- [ ] A página abre e funciona sem erros estruturais?
- [ ] Coloquei meu nome e uma descrição clara no Pull Request?
